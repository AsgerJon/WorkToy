## Summary

Method: the whole source (171 files) was read in import order before any probing; every entry above was then
confirmed by a repro script under the worktoy_env interpreter (3.14.5), with the version matrix checked on the
base_3_7 to base_3_14 envs. The repro scripts are kept at
/tmp/claude-1000/-home-AsgerJon-PycharmProjects-WorkToy/f4169923-10c8-4eea-ade9-c2c7b34c3b23/scratchpad/probes/
(a_... through ay_...). The existing audit files, BUGS.md and archive/audits were not opened, so overlap with
earlier sweeps is unknown. No file under src/ or tests/ was modified; notes.md is the only file written.

Counts: 8 BUG, 18 FLAW, 11 INCONSISTENCY, 4 NOTE, 18 DEAD END.

Highest impact first:
1. Metaclass-level annotations shadow 'type.__annotations__': every class built by an AbstractMetaclass-derived
