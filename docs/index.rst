worktoy
=======

A Python utilities library that adds runtime type enforcement,
declarative attributes, function overloading, and custom-metaclass
infrastructure on top of stock Python. Targets Python 3.7 through
3.14.

Installation
------------

.. code-block:: bash

   pip install worktoy
